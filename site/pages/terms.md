# 使用规则

本站是个人维护的聚合站：从公开信源抓取内容，用模型生成中文摘要与精选，原文版权归各来源所有。网页、RSS、公开 API 与 MCP 都可以匿名使用。

## 1. 本站是什么

本站不生产内容，只做聚合、筛选和索引：盯着一批公开信源，把同一件事的多篇报道归到一起，挑出一部分写成中文标题、摘要和推荐理由，每天 08:00 出一份日报，同样是每周一、每月 1 日出周报和月报。

页面上的标题、摘要和推荐理由由模型根据公开来源生成，**可能有错**。重要信息请点开原文链接核对，一切以原文为准。

## 2. 内容与版权

原文的文字、图片和版权归各来源所有。站内默认只展示摘要和指向原文的链接，只有来源明确允许时才展示全文。本站自己的标题、摘要、推荐理由、页面设计和代码由本站（及所用的开源框架）创作。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式（比如不希望被收录、不希望展示全文），请通过[反馈页](/feedback)告诉我，我会尽快处理。

## 4. 可以怎么用

可以直接使用：

- 个人阅读，用 RSS 订阅，或接到自己的阅读器里；
- 组织内部参考；
- 引用单条标题和摘要，并附上本站或原文的链接。

需要事先取得我同意：

- 用在商业产品或服务里，包括把本站当数据源转售；
- 整站或批量转载、镜像本站内容；
- 把本站内容用于训练模型或构建数据集；
- 去掉原文链接后再分发摘要。

## 5. 接口与频率

RSS、公开 API 和 MCP 都是匿名只读接口，没有账号，也不卖配额。使用时请：

- 按响应里的缓存时间轮询，不要高频全量拉取；
- 收到 429 时遵守 `Retry-After`，不要并发重试；
- 不要绕过限流，也不要制造异常流量；影响站点正常运行的来源可能会被封禁。

## 7. 规则变更

本页内容变更时，会更新上面的版本号和生效日期，并在[更新日志](/changelog)里记一笔。变更后继续使用，视为接受新版本。
