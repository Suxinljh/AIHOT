# 行业名录填写模板（WCH-35–38 用）

给汽车、游戏、影视三类各填一批品牌和信源。**不用一次填全，先给每类 8–12 个品牌、3–5 个信源就够开跑**，之后在后台继续加。

## 怎么填

- 直接在这个文件里改，或者在对话里按同样的格式贴给我，都行。
- 拿不准的列留空，我会补 ID、去重、合并同义名。
- 别名越多越好（中英文、简称、产品名都算），这是自动归组和搜索的依据。
- 信源不用先验证能不能打开，我会逐个实测；打不开的我会标出来问你换不换。
