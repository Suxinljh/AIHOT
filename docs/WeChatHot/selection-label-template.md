# 门槛校准标注模板（WCH-38 用）

目标：用你真实的选择，校准「什么值得写」的门槛，而不是凭感觉调数字。标注 30–50 条就能看出偏差；每个新行业（汽车、游戏、影视）至少 8 条。

## 怎么标

每条只回答一个问题：**这条事件，你会不会拿来做一篇公众号稿？**

- `选`：值得写，会进选题。
- `不选`：看过就算，不写。
- `说不准`：介于两者之间，写上理由（这类样本最有价值）。

还可以加一列 `原因`，用几个字说明：`信息太薄`、`旧闻`、`没增量`、`不是我的读者`、`有独家数据`、`影响面大`……

## 我会怎么用

1. 我按你的标注统计：选中的最低分、不选中的最高分、两类的重叠区间。
2. 用重叠区间反推门槛，而不是直接取平均；同时检查是不是某个维度在拖后腿（比如 `act` 对新闻类事件本来就应该低）。
3. 更新 `industry/selection.ts` 的门槛和 `tests/` 里依赖示例分数的断言，跑全量测试。
4. 校准结果写进 `docs/selection.md`，注明样本量和日期。

## 样本从哪来

- **推荐方式**：你在工作台里正常用几天，把「热点发现」里拿不准的事件标一下；我按 `wc_event_meta` 和 `publications` 导出成上面这张表（CSV/Markdown 都行）。
- **快速方式**：先给我 20–30 条你凭经验写下的「会写 / 不会写」标题，不需要真实分数，我用来校准提示词里的正反例。
- 标注不需要覆盖所有行业；先给你最熟悉的那个行业，效果最明显。

## 注意

- 不要为了「看起来均衡」硬凑比例；真实选择里的偏差正是要校准的东西。
- 同一事件的多篇报道只标一次，按事件标，不按文章标。
- 如果某条你觉得「标题党但内容有用」，标 `选` 并备注，我会检查是不是标题/摘要环节的问题，而不是门槛。
