# 公众号粘贴验收清单

用于 [WCH-27](../backlog) 的真机验收：在工作室「公众号」tab 点「复制富文本」，粘贴到微信公众号后台的图文编辑器，逐项对照。

## 准备

1. 工作台打开一篇有正文的稿件：标题、至少两级小标题、两段正文、一处加粗、一处链接、一张图片。
2. 点「复制富文本」。
3. 打开公众号后台 → 新建图文 → 正文区粘贴（不要用「粘贴并匹配样式」之外的额外清理）。
4. 在电脑端和手机预览（375px）各看一遍。

## 限制与已知丢失

- **图片地址**：公众号会重新抓取图片。当前图片存在本机 `.data/uploads`，只有管理员会话能读；粘贴前需要让公众号能访问该地址（公网域名或先手动上传图片）。这是 WCH-27 待解决的部署问题。
- **字体家族**：不写 `font-family`，用公众号自身字体；不同系统字体回退不同。
- **flex/grid、class、脚本**：序列化阶段已去掉，粘进去也不会有。
- **代码块**：`<pre><code>` 的背景与等宽字体在部分公众号模板会被改写，只保证文字不丢。
- **视频/外链卡片**：不在序列化范围内，粘贴后是纯文本链接。
- **表格**：TipTap 当前未启用表格，序列化器也不输出 table。
